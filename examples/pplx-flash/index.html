What this measures

Choose Wasm CPU or a WebGPU decoder with CPU tokenization and final readout. Both stream BF16 weights per layer; reads, uploads, dispatch and completion waits are included. WebGPU compute is synchronized wall time, not GPU timestamp time. Wasm memory excludes GPU allocations, JavaScript buffers and browser overhead. An optional worker prefetches weights. Small run counts do not establish stable p95 latency.
